# Native admission source checkpoint

This directory preserves reviewed qualification source and tests, following the existing source-only coordination convention. It is not a standalone runnable package or an execution release. Required qualification fixtures, raw captures, grants, release records and private review evidence are deliberately excluded from Git. Reproduce checks only in the corresponding complete offline qualification assembly, not by inventing replacement inputs.

The admission fix validates the fixed historical reconciliation baseline before native slot lookup or attempt effects. It refuses missing, changed, extra, oversized or redirected evidence, validates fixed source/profile/recovery inputs, and preserves UNKNOWN historical outcomes. The selector copies caller-owned mappings before validation. It never converts a historical absence observation into current absence or runtime authority.

The current complete offline assembly passed 101 preparation methods, including nine admission methods; the unchanged baseline selector has eleven passing independent methods. Guarded tests call the actual execute path but stop at a sentinel before any real slot. Native command bodies and failure/timeout behavior remain unchanged. The CLI hard-refuses release. These are offline source checks, not a successful native run or installed-package qualification.

Final executable review, fresh applicable runtime/security authority, current host/route/capacity checks and remaining native/installed/platform/fault qualification are separate prerequisites. No credential, environment file, private baseline capture or authority record belongs in this checkpoint.
